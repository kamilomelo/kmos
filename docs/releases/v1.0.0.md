# KMOS v1.0.0 — Arch Linux x86_64

The Arch x86_64 ISO installer supports fresh **headless** and **KDE** installs.
An installed KMOS headless system can be upgraded to KDE in one guided run.

## Install or upgrade

- **Fresh install:** boot an Arch x86_64 ISO, clone `main`, and run
  `./kmos-install.sh`. Choose headless or KDE, inspect the package and disk
  plan, then type `FORMAT` to approve formatting the selected partitions.
- **Headless → KDE:** on an installed KMOS headless machine, run
  `./platforms/archlinux/desktop/kde/kmos-headless-to-kde.sh` from a current
  checkout. This does not format disks or install AUR packages. Existing local
  regular users receive visual defaults in the same run; personal panels stay
  intact and differing settings require approval and backups.
- **NetworkManager:** the upgrade offers a separately confirmed *next-boot*
  handoff over working Ethernet or Wi-Fi. Active SSH is not interrupted during
  staging; reboot deliberately. After Wi-Fi-only staging, reconnect Wi-Fi in
  KDE at the local console before SSH can return. Old iwd passwords are not
  imported; a boot guard restores iwd/dhcpcd if NM cannot manage the device.

See the [quick start](../../README.md) and the
[upgrade and recovery guide](../arch-headless-to-kde.md).

## Changes since v0.9.0

- Shared Arch terminal tools and clear KDE base, applications, productivity,
  and optional Kamilo package layers. KDE includes Spectacle, Kdenlive and
  Firefox Developer Edition; guided repo-package entry remains available.
- Optional AUR consent before disk approval. If approved, `paru` is the default
  helper, `tododo-bin` is included, and other AUR packages are individual picks.
- Explicit Rust, PipeWire JACK, FFmpeg multimedia and English OCR providers to
  avoid package-manager provider questions.
- KMOS Dashboard icon on fresh panels without replacing Breeze icons or
  overwriting existing personal panels.
- Reviewable all-user KDE visual finishing and guarded NetworkManager handoff
  for headless → KDE upgrades.

## Verification and limits

Users reported successful fresh KDE and headless → KDE installs, including
all-user visuals and a Wi-Fi-only SSH upgrade to NetworkManager. A wired staged
handoff, KDE Wi-Fi, and internet with Ethernet unplugged were also checked on
hardware. Offline fixtures and Bash syntax checks passed; ShellCheck 0.11.0
was not available on the merge host. The **AUR-declined fresh install** and a
**failed Wi-Fi-only boot-guard recovery** have fixture tests but no hardware
failure test. Other platforms have separate, less mature workflows.

**Not supported:** converting an arbitrary existing Arch installation or VPS.
The ISO installer formats partitions; back up data and check the plan before
`FORMAT`. The `v0.9.0` tag is preserved unchanged.
