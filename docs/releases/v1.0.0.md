# KMOS v1.0.0 — Arch Linux x86_64

This release covers fresh Arch **headless** and **KDE** installation, a guided
KMOS headless → KDE upgrade, and experimental adoption of an installed headless
Arch x86_64 machine (including a VPS). Existing KDE installations are not an
adoption target. See the [quick start](../../README.md).

## Fresh ISO installation

Run `./kmos-install.sh` on an Arch x86_64 live ISO. Review the disk plan before
approving `FORMAT`: the root partition is formatted. An existing FAT EFI
partition defaults to reuse when it has sufficient free space. To force its
format, choose that action and type **`EREASE`** before the final `FORMAT`;
this also erases Windows boot files on that EFI partition. Partition changes
saved in `cfdisk` may take effect before `FORMAT`.

KDE packages are checked against the live ISO's repository databases before
disk approval and against the target before the KDE transaction. The obsolete
`kwin-x11` repository dependency was removed; `kwin` remains. An unavailable
package is reported by name instead of being retried four times. If the base
system and GRUB were installed but KDE stopped, **do not rerun the fresh
installer**. From a live ISO with the original root and EFI still mounted at
`/mnt` and `/mnt/boot`, run `./kmos-install.sh resume-kde` from a current local
checkout. It asks for KDE choices again and does not format partitions,
reinstall the base system or replace GRUB. See the
[recovery guide](../arch-headless-to-kde.md#resume-a-failed-iso-kde-stage).

A fresh Arch+KDE install was reported successful on a ThinkStation PX after
the package fix. The KDE-only resume path has offline fixtures, but has not
been field-tested on that machine.

## Existing systems

- **KMOS headless → KDE:** a separately guided upgrade applies KDE visuals to
  existing users without formatting. An optional, separately approved
  next-boot NetworkManager handoff preserves live SSH until reboot. For Wi-Fi,
  have local console access to reconnect in KDE after reboot. See the
  [upgrade guide](../arch-headless-to-kde.md).
- **Installed, headless Arch → KMOS headless (experimental):**
  `./platforms/archlinux/kmos-adopt-headless.sh --preflight` is read-only;
  the guided run installs headless tools, enables OpenSSH without restarting
  active sshd, optionally changes the hostname, and offers guarded account
  management. It requires an AUR helper and `tododo-bin`. Wheel membership
  alone does not grant sudo: new administrators are checked and per-user rules
  are offered with approval. The `--users-only` mode can manage accounts later
  without repeating package installation. See the
  [adoption guide](../arch-adopt-headless.md).

An initial VPS trial succeeded with yay and `tododo-bin`. An older `paru-bin`
failed to load `libalpm.so.15`; building paru from source reached a Rust
compiler SIGKILL. OOM is **not confirmed**. Account removal and sudo repair
remain fixture-tested, not field-verified. No adoption path converts an
existing KDE system.

## Limits

The ISO installer is destructive; never use it as an installed-system
converter. Arch package upgrades can run hooks and affect running services.
The Wi-Fi-only NetworkManager boot-guard failure path and KDE-only ISO recovery
have fixture coverage but no hardware failure test. Normal pacman caches remain;
KMOS does not automatically roll back disk changes, package upgrades or
account/home removal.
