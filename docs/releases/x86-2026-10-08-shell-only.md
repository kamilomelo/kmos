# KMOS x86 shell-only installation milestone — 2026-10-08

This corrected Arch Linux **x86_64 ISO installer** milestone includes the
headless and full KDE installation paths. A user completed fresh KDE installs
and confirmed the panel, Dashboard, widgets and clocks, and the transparent
wallpaper scaled without cropping against a black background. Headless and KDE
installation paths were also tested on real x86 hardware. AUR remains opt-in.

KMOS now stages a fresh-user-only KConfig panel preset and sets the first-login
wallpaper through Plasma's D-Bus API using a shell script. The current tracked
installer does not contain or generate KMOS-authored JavaScript. KDE itself
still ships its own Plasma scripts. Old KMOS JavaScript hook *filenames* remain
in safety checks so the installer can recognize and disable those hooks on
older installations without changing personal panel layouts.

The earlier tag [`x86-2026-10-08`](./x86-2026-10-08.md) is preserved for
history and **contains KMOS JavaScript**. This corrected milestone has its own
tag, `x86-2026-10-08-shell-only`; no published history was rewritten.

The ISO installer **formats the selected root partition and verified Arch EFI
partition**. cfdisk can save edits before `FORMAT`. It is not a converter for an
existing Arch system or VPS. Back up and verify the disk plan before proceeding.
Mirror ranking measures response time rather than large-package throughput;
NVIDIA downloads can be slow. Impala may fail on local `tty1`, so headless
Ethernet Wi-Fi setup also offers `iwctl`. Individual firmware, Wi-Fi reconnection
and first-login color-scheme hash combinations have not all been verified.

See the [README](../../README.md#start-here-arch-linux-x86_64) for instructions
and detailed safety notes. Further experimental changes belong on `x86/next`.
