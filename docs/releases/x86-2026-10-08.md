# KMOS x86 installation milestone — 2026-10-08

Scope: **Arch Linux x86_64 installation from an Arch ISO only**. This is a
snapshot of the working x86 installer, not a claim that Quartz64, Rocky Linux,
or an existing Arch system can be installed or converted in the same way. The
tag `x86-2026-10-08` identifies the exact repository snapshot.

## What works

- The user has completed fresh x86 headless and full KDE installations on real
  hardware. KDE's fresh panel layout was checked on a fresh login.
- The installer makes the headless/KDE choice explicitly, offers optional AUR
  installation, verifies its disk/EFI target, and requires `FORMAT` before
  formatting the chosen Arch partitions. It does not intentionally format a
  Windows EFI partition.
- It can hand off a working ISO Wi-Fi connection; headless keeps iwd/WPA
  first-boot behavior separate from KDE's NetworkManager migration.
- KDE provides KMOS defaults for a *new* Plasma layout without rewriting
  existing users' panels or color selections.

## Limits and checks for new installations

- **Back up first.** cfdisk may save partition-table edits before the installer
  requests `FORMAT`. Never run the ISO installer on an installed system or VPS.
- Mirror probing measures response time of a small sample, **not** sustained
  package-download speed. NVIDIA packages may take a long time to download.
- The later headless Ethernet Wi-Fi helper at
  `/opt/kmos/bin/kmos-headless-wifi.sh` offers Impala or text-based `iwctl` and
  asks you to check the saved iwd network. That revised helper has mocked tests,
  but its persistence after reboot has not yet been verified on a fresh install.
  Impala has been reported to fail on a laptop's local `tty1`; use `iwctl`
  there. It worked in the reported SSH session.
- The KMOS first-login color fix and terminal font changes have mocked checks;
  do not treat every device, firmware, and user preference as field-verified.
- ShellCheck 0.11.0 was unavailable on the development host for the full local
  check suite. See the [README](../../README.md) for local validation.

## Next direction

The current release remains an ISO installation reference. Work on `x86/next`
will separate a reusable headless base from an add-on KDE layer, then consider
safe adoption of existing Arch/VPS systems and finer package choices. Those
features are **not** part of this milestone. Headless AUR remains opt-in.

See the [README](../../README.md#install-arch-x86_64) for quick-start commands
and essential safety notes.
